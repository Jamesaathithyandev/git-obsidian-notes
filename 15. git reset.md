Used to move HEAD to another commit.

### Soft

```
git reset --soft HEAD~1
```

- Removes commit.
- Keeps changes staged.

### Mixed

```
git reset HEAD~1
```

- Removes commit.
- Keeps changes unstaged.

### Hard

```
git reset --hard HEAD~1
```

- Removes commit and changes.

⚠️ `--hard` can permanently discard work.
