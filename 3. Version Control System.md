A **Version Control System (VCS)** manages different versions of files over time.

### Types

#### Local VCS

Version history is maintained only on the local machine.

#### Centralized VCS

A central server stores the repository.

Example:

```
Developer → Central Server ← Developer
```

#### Distributed VCS

Every developer can have a complete copy of the repository and its history.

**Git is a Distributed Version Control System.**

```
Developer A → Repository
Developer B → Repository
Developer C → Repository
```
