**Git** is a **distributed version control system (VCS)** used to track changes in source code.

It allows developers to:

- Track changes
- Save different versions of a project
- Work on different features independently
- Collaborate with other developers
- Revert unwanted changes
- Maintain project history

### Simple idea

```
Project
   ↓
Git tracks changes
   ↓
Multiple versions / commits
   ↓
Easy collaboration & recovery
```

Git runs **locally on your computer**.
