Temporarily saves uncommitted changes.

```
git stash
```

View stashes:

```
git stash list
```

Restore:

```
git stash pop
```

Apply without removing:

```
git stash apply
```

### Use case:

```
Working on Feature A
        ↓
Need to switch branches
        ↓
git stash
        ↓
Do other work
        ↓
Return to Feature A
        ↓
git stash pop
```
