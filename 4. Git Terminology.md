
| Term              | Meaning                                 |
| ----------------- | --------------------------------------- |
| Repository        | Project tracked by Git                  |
| Working Directory | Current files you're working on         |
| Staging Area      | Changes selected for the next commit    |
| Commit            | Snapshot of changes                     |
| Branch            | Independent line of development         |
| Merge             | Combining branches                      |
| Remote            | Repository hosted elsewhere             |
| Clone             | Copy a remote repository locally        |
| Push              | Upload local commits                    |
| Pull              | Download and integrate remote changes   |
| Fetch             | Download remote changes without merging |
| HEAD              | Current position/commit                 |
| Origin            | Default name of the remote repository   |

### Basic Git workflow

```
Working Directory
        ↓
     git add
        ↓
Staging Area
        ↓
   git commit
        ↓
Local Repository
        ↓
    git push
        ↓
Remote Repository
```
